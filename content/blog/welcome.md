Tanuki brings Catppuccin colors, Geist typography, and a light/dark toggle to
your Zola site.

## Getting started

Add the theme as a submodule and set it in your config:

```bash
git submodule add https://github.com/raskell-io/tanuki themes/tanuki
```

```toml
theme = "tanuki"

[extra]
mode = "blog"
```
